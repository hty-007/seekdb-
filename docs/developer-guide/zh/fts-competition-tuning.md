# 全文索引调优

基于官方 `2026-competition` 的 `5bce9e06d1281347ad61344e4b01fab9158c58a2`。

- `TOKENIZE` 直接使用默认解析参数，省去 JSON 序列化和回读。默认 UTF-8 分词在分词器内读取内置词典，显式参数和其他字符集沿用校验路径。
- IK 在进程内共享只读的内置词典，按需初始化并在缓存关闭前释放。BENG 将归一化后的词直接写入调用方分配器。
- 索引构建执行器复用工作线程私有的词频表。桶容量按需增长，每份文档开始前清除上一份文档的词条。
- `MATCH` 只作为自然语言真值谓词时，倒排扫描只投影文档 ID，省去 BM25 所需的统计与评分。需要相关度或排序的查询使用评分路径。
