# 全文索引调优

基于官方 `2026-competition` 的 `5bce9e06d1281347ad61344e4b01fab9158c58a2`。

- `TOKENIZE` 直接使用默认解析参数，省去 JSON 序列化和回读。显式参数仍走原有校验路径。
- 索引构建执行器复用工作线程私有的词频表。桶容量按需增长，每份文档开始前清除上一份文档的词条。
- 自然语言 `MATCH` 只作为真值谓词时，执行器直接合并命中文档 ID，省去 BM25 所需的统计与评分。查询需要相关度或排序时继续使用评分路径。
